# 왜 강화학습을 배우는가?

강화학습은 AI가 **환경(Environment)** 과 상호작용하며
보상(Reward)을 최대화하도록 학습하는 방법이다.

우리가 GridWorld를 만드는 이유는

- Python 구현 능력
- 객체지향 사고
- 환경(Environment) 설계
- AI가 상태(State)를 어떻게 인식하는지

를 직접 이해하기 위해서이다.
