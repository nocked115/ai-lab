# 🧠 Hands-On Machine Learning

> Part of my AI Lab — Learning ML by building, breaking, and rebuilding.

## 🎯 Goal

Develop the ability to independently design, implement, evaluate,
and deploy machine learning systems.

Focus:
- Data Science
- Machine Learning
- AI Engineering
- MLOps fundamentals

## 📖 Main Textbook

Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow
(2nd Edition)

## 🔄 Learning Workflow

Each mission follows this process:

| Stage | Description |
|---|---|
| 1. UNDERSTAND | Learn and explain the concepts |
| 2. READ | Understand the example code |
| 3. RUN | Execute the textbook examples |
| 4. REBUILD | Implement independently from scratch |
| 5. BREAK | Modify parameters and observe results |
| 6. TRANSFER | Apply concepts to a new dataset |
| 7. ENGINEERING | Refactor and improve code quality |
| 8. EXPLAIN | Explain without relying on AI |
| 9. COMMIT | Record results and reflections |

Not every mission requires all nine stages.

## 🤖 AI Assistance Rules

1. Attempt the task independently.
2. Check documentation and error messages.
3. Refer to the textbook.
4. Ask AI for hints.
5. Request full code only when necessary.
6. Rebuild AI-assisted code independently afterward.
